# Danh Le — AI/ML Portfolio

A fast, responsive portfolio for Le Nguyen Thien Danh, built with semantic HTML, modern CSS, and lightweight vanilla JavaScript.

## Highlights

- Kinetic hero typography and short loading transition
- Scroll progress, reveal, parallax, counter, card-tilt, and cursor interactions
- Responsive bento layouts for projects, profile, and skills
- `prefers-reduced-motion` support for accessibility
- Zero build dependencies
- Automatic GitHub Pages deployment

## Run locally

Open `index.html` directly or serve the folder with any static server.

```bash
python -m http.server 4174
```

Then visit `http://localhost:4174`.

## Deploy

Push to the `main` branch. The workflow in `.github/workflows/pages.yml` publishes the site automatically through GitHub Pages.
